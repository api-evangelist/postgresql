I’m pleased to announce the first public release of pglifecycle , an open source schema management tool for PostgreSQL. pglifecycle keeps your database schema in version control as structured YAML, with one file for each table, view, function, role, and other object. This makes the current schema easy to browse, review, and change without reconstructing it from years of migration files.
