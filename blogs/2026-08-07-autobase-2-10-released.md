Autobase 2.10 expands day-to-day PostgreSQL operations with new cluster management capabilities. Administrators can now perform common cluster actions directly from the Console UI, configure advanced system settings, deploy clusters using the local disk, and automate maintenance with an extended set of Ansible playbooks. See the full details in the release notes .
