The release adds a PostgreSQL Debugger, visual editors for event triggers, functions and procedures, as well as file attachments and model choice in dbForge AI Assistant. Devart, a leading developer of database management software, has released dbForge 2026.2 , the latest update to its unified ecosystem of professional database tools. The new version adds a brand-new embedded PostgreSQL Debugger and visual object editors to dbForge Studio for PostgreSQL.
