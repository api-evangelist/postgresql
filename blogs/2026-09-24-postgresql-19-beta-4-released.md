The PostgreSQL Global Development Group announces that the fourth beta release of PostgreSQL 19 is now available for download . This release contains PostgreSQL 19 feature previews ahead of general availability, though some details of the release can change during the beta period. You can find information about all of the PostgreSQL 19 features and changes in the release notes : https://www.postgresql.org/docs/19/release-19.html The next planned release of PostgreSQL 19 is the release candidate, which should occur in early October.
